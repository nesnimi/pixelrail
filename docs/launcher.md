# Pixel Launcher — кандидат v3.1.0

Одиночный Super открывает прежнее окно снизу слева рядом с Sidebar. Ширина 540 px,
поиск 48 px, иконки 32 px, поверхности/состояния Material You. Original/Pixel Themed
обновляются без перезапуска. Отдельного процесса Launcher нет.

## Пустой запрос

До восьми приложений в сетке. Учитываются реальные Categories и запуски через
Launcher. Для fallback предпочтительны пользовательские задачи: браузер, терминал,
файловый менеджер, редактор, офис, графика, мультимедиа и другие основные категории.
Конкретные программы не зашиты в код. Settings/HardwareSettings/Mixer/FileTools и
аналогичные помощники не заполняют сетку по алфавиту. FileManager остаётся допустимым,
даже если desktop-файл дополнительно содержит FileTools/System.

Два осознанных запуска могут поднять утилиту без подходящей категории. Единичный
запуск помощника не вытесняет пользовательские приложения. Существующего источника
закреплённых приложений в PixelRail нет; новый редактор избранного не добавлялся.
Если подходящих кандидатов нет, показывается обычный список, без случайной сетки.
Блока быстрых действий в Launcher больше нет; команды/хоткеи сохранены.

## Desktop entry и поиск

Native DesktopEntries остаётся источником имён, иконок и запуска. Quickshell 0.3.2
не экспортирует OnlyShowIn/NotShowIn и не фильтрует их в applications. Поэтому
`launcher_entries.py` один раз асинхронно читает только XDG applications-каталоги
(повторно — при изменении native-каталога), без индекса/демона/polling.

Учитываются Hidden/NoDisplay, пользовательский приоритет XDG, OnlyShowIn/NotShowIn
и Categories. XDG_CURRENT_DESKTOP разбирается как список через `:`; при отсутствии
значения для целевого окружения используется Hyprland. Ограничения рабочего стола
применяются к стартовому экрану; явный запрос может найти системную/внешнюю утилиту.
Hidden/NoDisplay остаются исключёнными и из явного поиска. Одинаковые команды с
одинаковыми Terminal/рабочей папкой объединяются; разные аргументы/профили сохраняются.

Ранжирование: точное название → начало названия → остальные совпадения. Сохранены
id/genericName/keywords, несколько слов и кириллица. Файловый поиск не имитируется.
При отказе metadata reader остаётся список/поиск; закрытие и IPC не блокируются.

## Управление и данные

Стрелки: пространственная навигация по сетке, ↑↓ по результатам. Tab/Shift+Tab:
следующий/предыдущий элемент; Enter: запуск; Esc: закрытие. Alt+Shift остаётся
биндом Hyprland, поиск не подменяет раскладку. Повторный Super закрывает Launcher.
Фокус, outside click и Screenshot Mode используют прежнюю реализацию.

Частота: `${XDG_STATE_HOME:-$HOME/.local/state}/pixelrail/launcher.json`, максимум
64 desktop-id, без запросов поиска. FileView читает асинхронно и сохраняет атомарно
только после запуска. Настройки темы и данные не находятся внутри releases.

## Проверка / установка

`python tests/launcher-entries.py`, `python tests/launcher-ui.py`, Qt6 QtTest,
`lua tests/super-tap.lua`, `lua tests/binds.lua`. UI тест использует отдельный HOME
и безопасный Exec; реальные клавиши/Alt+Shift/outside click проверяет владелец T480.

Установка и откат: [installation](installation.md), [финальный кандидат](release-v3.1.0.md).
Отсутствующий IPC сообщает о восстановлении через pixelrail-shell/rollback;
Rofi не является маршрутом Launcher.
