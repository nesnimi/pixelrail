# Public screenshot provenance

These are actual QML `grabToImage` captures from private offscreen/software Qt
test windows. They are not generated artwork, personal desktop screenshots or
proof of device availability. Current UI text is primarily Russian.

- `launcher.png`: final candidate Launcher UI test, fixture `.desktop` entries,
  bounded synthetic usage data, Pixel Themed Material/fallback icons.
- `settings.png`: approved RC3 Control UI fixture, appearance page in the real
  Control Center layout. Colors and preferences are private test values.
- `notifications.png`: RC4 Control UI empty-history fixture, no personal messages.

No user wallpaper, network SSID, clipboard contents, account or private path is
shown. Layout/fixture code is MIT; rendered Material Symbols and Roboto originate
from the separately licensed bundled resources. See THIRD_PARTY_NOTICES.md.
Local reference artwork and historical development captures are excluded.
