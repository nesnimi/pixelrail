# PixelRail v3.1.0 — release draft

Publication candidate, not a claim of acceptance on another computer. Create a
GitHub **draft** release after owner review; publish only after hardware acceptance.

## Highlights

Pixel Experience components share Material You, Rounded symbols and typography:
Sidebar, Launcher, Quick Settings, Notifications, Settings, Clipboard, Wallpaper
Picker and OSD. Launcher uses real desktop metadata/categories/usage and contains
no duplicate quick-action block. Native notification ownership, screenshot cleanup,
live sliders and existing shortcuts are preserved.

## Installation and recovery

`install.sh` wraps existing deploy/rollback. Dry-run is default; dependency/native
checks, backups, reviewed unmanaged conflicts and IPC readiness precede activation.
`uninstall.sh` restores the full install chain while preserving user data/backups.
No package installation, root privileges, service management or hardware tuning.

## Assets

- `pixelrail-3.1.0-source.tar.gz`: reproducible source snapshot; no `.git`, cache,
  secrets, raw reference artwork, GoogleDot binaries or precompiled Qt plugin.
- `SHA256SUMS`: SHA-256 of the source archive.
- GitHub-generated source archives from the reviewed tag remain available.

`RELEASE.json` inside the explicit archive records revision, dirty/candidate status,
version and absence of bundled native binaries/history. A dirty working-tree
snapshot is a candidate, not a verified tag build.

## Requirements / limitations

Validated target: Arch Linux, Hyprland 0.57.x Lua, Quickshell 0.3.2. Build the native
plugin against installed Qt/private headers. Other distributions/Quickshell ABI
versions and a second real computer are unverified. Interface text is primarily
Russian; documentation/search support English and Russian, not full UI i18n.

Per-user install layout is standard HOME/.config and HOME/.local; nonstandard
persistent XDG roots are refused for live apply. Optional devices/backends can be
unavailable; original app shortcut commands may need explicit owner customization.
Waybar/SwayNC fallback and GoogleDot require separate available dependencies.

Original code: MIT, nesnimi. Roboto: OFL, Material Symbols: Apache-2.0. GoogleDot
is GPL-3.0 and optional; it is not shipped as a binary theme. See notices.

## Acceptance

Isolated fresh/update/conflict/failure/rollback/uninstall tests, QML/runtime and
the existing functional regressions are required. See publication report and
[second-computer checklist](../second-computer-checklist.md). No claim about
improved battery life, other distributions or physical hardware is made here.
